## 修改内容

- 在 host watchdog 中新增：
  - `FIRESIM_RUNWORKLOAD_LIVE_IDLE_TIMEOUT_SECONDS`
  - `FIRESIM_MONITOR_HEARTBEAT_LIVENESS_ENABLE`
- guest-visible idle 与 heartbeat idle 分开追踪：
  - `idle` 继续表示 guest 文件前沿静默时间
  - `hb_idle` 表示 heartbeat 停止前进的时间
- `600s` 级别的旧 `idle_timeout_seconds`
  现在只在 heartbeat 也 stale 时触发
- 当 heartbeat 仍持续前进时，
  改用更长的 `live_idle_timeout_seconds`
  作为兜底超时
- `scripts/firesim-tmux-run.sh`
  help 文本同步新增新环境变量说明
- `scripts/firesim-tmux-run.sh`
  透传环境变量时，
  额外保留
  `PIPELINE_RUNTIME_DEBUG_TRIGGER_*`
  前缀，
  避免后续 trigger overlay 在 wrapper -> tmux 边界丢失

## 原因

- 当前 `g6 bertmini` 直接证据表明：
  `guest_sparse` plateau 与 pointwise quiet window 可以持续很久，
  但 heartbeat 仍在稳定推进。
- 直接把 heartbeat 算进 progress 会让 watchdog 对真实 software deadlock 失效；
  双层超时更适合当前调试约束。

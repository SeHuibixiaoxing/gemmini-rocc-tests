## Rationale

Remote gdbserver for the cfg32 NIC target is meant to debug actual
`pipeline-runtime` hangs. The existing RISC-V binary was `not stripped` but did
not contain `.debug_info` or `.debug_line`, so GDB would have function symbols
but not source-line/type information. The new default flags add `-g3` and
`-fno-omit-frame-pointer` while keeping `-O2`.

### 2. 新增 preserve runtime config

新增：

```text
sims/firesim/deploy/config_runtime_f2_rocket_singlecore_nic_gdbserver_smoke_notrace_preserve_30mhz.yaml
```

与普通 no-Trace smoke runtime 的关键差异：

```yaml
workload:
  terminate_on_completion: no
  suffix_tag: f2-rocket-singlecore-nic-gdbserver-smoke-notrace-preserve
```

用途：允许 manager 或 workload 异常时保留 run host，先手动抓现场。

### 3. 新增现场采集脚本

新增：

```text
scripts/capture_firesim_nic_debug_scene.sh
```

支持：

```bash
capture_firesim_nic_debug_scene.sh start-tcpdump <run-host-private-ip> [tag]
capture_firesim_nic_debug_scene.sh capture <run-host-private-ip> [tag] [outdir]
```

采集内容包括：

- `screen -ls`
- `sim_slot_0/uartlog`
- `sim_slot_0/heartbeat.csv`
- `sim_slot_0/niclog0`
- `switch_slot_0/switchlog`
- `tap0` link/addr/neigh
- tcpdump pcap / tcpdump log

脚本只采集和拷回，不终止 run farm。

## 背景

- 本轮在 `page24` trigger rerun 启动后，静态确认新的观测缺口：
  - workload `outputs` 未列出 `bertmini-batch8.trigger.log`

- 这会导致：
  - 即使 guest 内 trigger 命中并写出了 `trigger.log`
  - run 结束或 watchdog 抓取后，本地仍可能缺少这份关键证据

  `/home/ubuntu/chipyard/scripts/firesim-prt-host-watchdog.sh`
- 具体内容：

    `/root/pipeline-runtime-debug/bertmini-batch8.trigger.log`
  - 在 `capture_remote_state()` 中新增：
    - `debugfs` 抓取 guest `trigger.log`
    - 输出文件：
      `*.guest-trigger-log.txt`

    - `trigger.log` 大小探测
    - `GUEST_TRIGGER_LOG_SIZE`
      回传
    - progress / idle 日志中展示
      `guest_trigger=...`
  - 将 `trigger.log` 增长纳入 host watchdog 的“前进”判据

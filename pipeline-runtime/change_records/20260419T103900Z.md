## 修改目的

- 响应“不要 `Linux + metasim`”的新约束。
- 保留 pair-manager 主线语义不变，
  但把动态窗口压缩到几条 ReRoCC CSR + 一条极小 DMA。
- 为后续 `TraceV selector=3` 提供可直接命中的 marker。

## Probe 默认语义

- `NUM_CORES=4`
- `NUM_GEMMINI=12`
- `NUM_DMA=12`
- `GEMMINI_BASE_ID=0`
- `DMA_BASE_ID=0`
- `PAIR_MANAGER_MODE=1`
- `cfg_id=0`
- `manager_id=0`
- `bytes=4096`
- `mode=2`
- `tracerv_markers=1`

## 关键实现点

- 默认 critical window：
  `raw release -> immediate RROPC3 restore`
- 关键日志只放在目标 CSR 前后：
  - `before-raw-release`
  - `after-raw-release`
  - `before-readback` / `after-readback`
  - `before-restore-opc3` / `after-restore-opc3`
- 直接把 instruction trigger marker 编到最终 ELF：
  - start：`0x00008013`
  - end：`0x00010013`

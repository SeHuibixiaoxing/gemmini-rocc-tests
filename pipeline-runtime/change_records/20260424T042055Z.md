## 修改原因

之前直接在大配置上调 `NIC + gdbserver + pipeline-runtime`，
问题空间太大，容易把以下因素混在一起：

- NIC 设备是否真正存在
- host bridge 是否稳定
- guest Linux 网络是否起来
- `gdbserver` 是否能正常监听
- pipeline-runtime 自身是否卡死

所以本轮改动的目标是先把“拿到 guest PC / 栈 / 指令”的最小能力单独拉起来，
后续再把这条能力迁移回主线。

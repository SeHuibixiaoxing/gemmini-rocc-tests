## Root Cause

- `v23` tried to "turn off" the temporary page-52 proof window by setting:
  - `PIPELINE_RUNTIME_DMA_EXPORT_PAGE_START=""`
  - `PIPELINE_RUNTIME_DMA_EXPORT_PAGE_END=""`
- But `prt_dma.c:dma_should_sparse_export_page_probe()` treats an unset page range as
  "use the built-in fallback sparse pattern", not "disable sparse export page logs".
- That fallback reopened hot-path export logging for `page>=48`, first page, last page,
  and `page%8==0`.
- As a result, `v23` was noisier than intended and could not be used as the authoritative
  low-perturbation control rerun.

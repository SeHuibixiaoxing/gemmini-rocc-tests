## Scope

在 pairdummy sbus128 dummy-model 主线上补齐“breadcrumb-only 低扰动 rerun”所需的 host 侧 overlay 能力，并把该机制写入 workflow / observability 文档。

## Files Changed

- `scripts/render_pairdummy_guest_env.sh`
- `docs/workflows/pairdummy_sbus128.md`
- `docs/testing/observability.md`

## Functional Change

`render_pairdummy_guest_env.sh` 过去只允许临时覆盖 `PIPELINE_RUNTIME_DEBUG_TRIGGER_*`。
本次扩展为同时允许覆盖以下少量 breadcrumb 变量：

- `PIPELINE_RUNTIME_BREADCRUMB_ENABLE`
- `PIPELINE_RUNTIME_BREADCRUMB_PATH`
- `PIPELINE_RUNTIME_BREADCRUMB_SEGMENT`
- `PIPELINE_RUNTIME_BREADCRUMB_GLOBAL_STAGE`
- `PIPELINE_RUNTIME_BREADCRUMB_LOCAL_STAGE`
- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH`
- `PIPELINE_RUNTIME_BREADCRUMB_STAGE_RADIUS`
- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS`

这使得后续 rerun 可以在不启用 trigger 的情况下，仅通过收窄 breadcrumb 过滤条件来减少 guest 文件写入量。

## Validation

本地验证命令：

```bash
tmpenv=$(mktemp)
PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH=5 \
PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS=0 \
PIPELINE_RUNTIME_DEBUG_TRIGGER_ENABLE=0 \
generators/gemmini/software/gemmini-rocc-tests/pipeline-runtime/scripts/render_pairdummy_guest_env.sh "$tmpenv"
rg -n "PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH|PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS|PIPELINE_RUNTIME_DEBUG_TRIGGER_ENABLE" "$tmpenv"
```

验证结果：

- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH='5'`
- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS='0'`
- `PIPELINE_RUNTIME_DEBUG_TRIGGER_ENABLE='0'`

## Rationale

上一轮 `dma-fixed-load/page63` rerun 已证明 trigger 家族自身会前移 frontier。
因此下一轮主探针应避免继续在 DMA 固定页热路径上做 trigger 匹配，而改为 breadcrumb-only 收窄。

# 20260426T075700Z F2 TIMING strategy wiring

调试类别：gdbserver

## 修改目标

静态排查 `build_strategy: TIMING` 是否真的进入 AWS F2 bitstream build。

结论：FireSim manager 会把 YAML 中的 `build_strategy: TIMING` 传给
`platforms/f2/build-bitstream.sh --strategy TIMING`，但 F2 私有 wrapper
此前没有把该值继续传入 AWS shell Tcl flow。F2 `aws_build_dcp_from_cl.py`
也没有通用 `--strategy` 参数，真正可用的是本仓库已有的
`strategy_TIMING.tcl` 及其 `synth/place/phys/route` directive 变量。

## 修改

### `sims/firesim/platforms/f2/build-bitstream.sh`

- 导出 `BUILD_STRATEGY=$STRATEGY`
- 打印 `Using BUILD_STRATEGY=...`

### `sims/firesim/platforms/f2/aws-fpga-firesim-f2/hdk/common/shell_stable/build/scripts/build_all.tcl`

- 读取 `BUILD_STRATEGY`
- 加载 `${HDK_SHELL_DIR}/build/scripts/strategy_${BUILD_STRATEGY}.tcl`
- 将 strategy 中的变量映射为 flow 内部变量：
  - `STRATEGY_SYNTH_OPTIONS`
  - `STRATEGY_SYNTH_DIRECTIVE`
  - `STRATEGY_OPT_OPTIONS`
  - `STRATEGY_OPT_DIRECTIVE`
  - `STRATEGY_PLACE_OPTIONS`
  - `STRATEGY_PHYS_OPT`
  - `STRATEGY_PHYS_OPTIONS`
  - `STRATEGY_ROUTE_OPTIONS`
  - `STRATEGY_ROUTE_PHYS_OPT`
  - `STRATEGY_POST_PHYS_OPTIONS`
  - `STRATEGY_POST_PHYS_DIRECTIVE`
- 若 strategy 文件不存在，改为 `exit 1`
- 在 build banner 中打印有效 strategy 和 directive/options

### `.../build_level_1_cl.tcl`

- `opt_design`、`place_design`、`phys_opt_design`、`route_design`
  改为按 strategy 动态组装命令
- 支持 TIMING 的：
  - `place_directive ExtraNetDelay_high`
  - `phys_directive AggressiveExplore`
  - `route_options -tns_cleanup`
  - `route_directive Explore`
  - `route_phys_opt 1`
  - post-route `phys_opt_design -directive AggressiveExplore`

### `.../hdk/cl/developer_designs/cl_firesim/build/scripts/synth_cl_firesim.tcl`

- 模板中的 `synth_design` 改为按 `STRATEGY_SYNTH_OPTIONS` /
  `STRATEGY_SYNTH_DIRECTIVE` 动态组装
- 保留无 strategy 时的 legacy fallback：`-keep_equivalent_registers`

另：当前生成目录
`cl_f2-firesim-FireSim-FireSimRocketNICNoTraceConfig-BaseF2Config`
中的 `synth_cl_firesim.tcl` 也已具备同样的 dynamic synth command，
保证下一轮直接复用当前 CL 目录时 synthesis 侧也能吃到 TIMING。

## 静态验证

- `bash -n sims/firesim/platforms/f2/build-bitstream.sh` 通过
- 本地 `strategy_*.tcl` 均定义完整 14 组变量
- `origin/main` 的公开 FireSim platform 列表没有 `platforms/f2`；
  因此不能直接用上游 FireSim main 的 F2 路径做同名对比
- 本地 F2 shell 文档和 `cl_firesim/build/scripts/README` 明确要求使用
  strategy TIMING

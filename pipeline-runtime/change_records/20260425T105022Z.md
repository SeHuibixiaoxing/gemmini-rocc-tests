## 修改内容

### 1. SimpleNIC ready 链路修复

把 `hPort.toHost.hReady` 从：

```scala
hPort.fromHost.hReady && localQueuesReady
```

改为：

```scala
localQueuesReady
```

原因是生成后的 `hPort.fromHost.hReady` 由 `targetCycleFinishing` 反推，而 `targetCycleFinishing` 又等待 NIC output source ready。旧写法会形成组合依赖环。

token 的实际消耗/产生仍由 `tFire` 控制，不放松语义提交点。

### 2. TargetCycleDebugWidget 深化

新增可综合派生 blocker：

- HostPort to/from blocked。
- wire input missing valid / backpressured。
- wire output blocked。
- ready-valid input/output 的 forward/reverse blocker。

每类 blocker 都有：

- live/first/last mask。
- cycles/streak/max_streak。
- 每个 endpoint 的 bit_count。

host driver 新增：

- `TARGETCYCLE DEBUG BLOCKER_STATS`
- `TARGETCYCLE DEBUG BLOCKER_COUNT`
- `TARGETCYCLE DEBUG BLOCKER [live|first|last]`

### 3. SimpleNIC 现场深化

新增 SimpleNIC 可综合寄存器和 host dump：

- `debug_cycle`
- `current_blocked_reason`
- `first_blocked_reason`
- `last_blocked_reason`
- first/last blocked cycle
- last tFire / PCIE in / PCIE out cycle
- target-cycle/local-queue/PCIE/to-host-ready streak 和 max streak

blocked reason bit 直接解码：

- `to_host_valid_missing`
- `from_host_ready_missing`
- `ntht_enq_not_ready`
- `htnt_deq_not_valid`
- `hport_to_host_blocked`
- `hport_from_host_blocked`
- `pcie_in_backpressured`
- `pcie_out_backpressured`

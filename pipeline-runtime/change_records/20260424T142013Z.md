## 修改原因

- 之前已经确认：
  - 仅靠 `SimpleNICBridge` lockstep patch 不能解决当前 `SimpleNIC` host-side token mismatch。
- 但之前 host dump 只看到：
  - `requested_bytes`
  - `actual_bytes`
  - `currentround`
  - `poll byte`
- 这不足以回答真正卡在哪一层：
  - `tFire` 门控没放行；
  - queue occupancy 漂移；
  - adapter 7-beat 聚合没收敛；
  - 还是 host-side bulk 语义本身。

因此本轮的策略是：

- 不再增加持续性 hot-path 文本日志；
- 改为只在 host 失败瞬间，读取一组只读 snapshot reg。

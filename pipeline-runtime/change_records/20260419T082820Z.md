## 修改原因

- 当前成功的最小 `hello-marker` metasim 路线，
  已经证明 `selector=3` 精确指令触发本身是可用的。
- 当前更需要固化的是方法论：
  - 先最小样例
  - 再 workload-shaped 轻量 variant
  - 最后才上 full-size / FPGA
- 如果不把这轮经验沉淀成 SOP，
  后续很容易重新回到：
  - 盯着 `TRACEFILE-C* == 0`
  - 一轮轮加日志
  - 把 marker 未执行到误判成 `TracerV` 故障

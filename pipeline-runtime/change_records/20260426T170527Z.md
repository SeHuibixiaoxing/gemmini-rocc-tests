## 修改内容

### NIC / SimpleNIC

- `SimpleNICBridge.scala`
  - 保留 `fromHostValidDrive = htnt_queue.io.deq.valid`，避免重新引入 ready/valid 互等。
  - `macAddr`、`rlimit`、`pauser` 的 `valid` 改为和 `nicIn.valid` 同源。
  - `htnt_queue.io.deq.ready` 改为整组 fire 条件。
  - 增加 from-host group blocked / partial-fire / HTNT token 快照寄存器。
  - 修复 `lastFromHostPartialFireMask` 重复定义导致的 Scala 编译错误。

- `simplenic.h` / `simplenic.cc`
  - 增加新增 MMIO register 字段。
  - `dump_host_debug()` 打印 from-host group/partial 快照。

- `FPGATop.scala`
  - `TargetCycleDebug` 对 `ChannelizedHostPortIO` 不再全报 0。
  - 聚合每个 channelized bridge 的 to-host/from-host `valid/ready`，便于全局 blocker 快照显示 SimpleNIC bridge 层面状态。
  - 修复 helper 类型签名以通过 Scala 编译。

### target 本地 gdb 路径

- `gdbserver-smoke.c`
  - 增加 `GDBSERVER_SMOKE_SLEEP_ITERS` 环境变量。
  - 默认仍为 5 轮 sleep，保持原 gdbserver smoke 行为。
  - 设置为 0 时快速退出，适合本地 gdb batch smoke。

- `run_local_gdb_smoke.sh`
  - 默认 `LOCAL_GDB_SMOKE_SLEEP_ITERS=0`。
  - 默认 timeout 从 1800 秒降到 300 秒。
  - gdb command file 中设置 `GDBSERVER_SMOKE_SLEEP_ITERS`。

- `run_interactive_gdb_shell.sh`
  - UART 提示中补充 `set environment GDBSERVER_SMOKE_SLEEP_ITERS 0`。
  - 优先使用 `setsid cttyhack /bin/sh -i`，改善控制终端与 Ctrl-C 行为；没有 `cttyhack` 时回退原 `/bin/sh -i </dev/console`。

# 移除 firesim_top.cc 中残留的 OCL debug 方法调用

日期：2026-05-02T16:49:47Z

## 背景

为把 single-core NIC 硬件回到 old AGFI 已知通过方向，前一轮已经移除了临时加入的
OCL/control-plane synthetic debug 寄存器：

- `SimulationMaster` 的 `HEALTH_*`；
- `ClockBridge` 的 clock debug regs；
- `PeekPokeIO` 的 peek-poke debug regs；
- `TargetCycleDebugWidget` 对 OCL ctrl channel 的采样。

但第一次 fresh build：

```text
rocket-singlecore-nic-notrace-regress-build-20260502-1645
```

在本地 driver 编译阶段失败，因为
`generators/firechip/chip/src/main/cc/firesim/firesim_top.cc` 仍调用已经删除的方法：

```text
master.log_runtime_state(...)
clock.log_debug_state(...)
peek_poke.log_debug_state(...)
```

## 修改

修改文件：

```text
generators/firechip/chip/src/main/cc/firesim/firesim_top.cc
```

修改内容：

- 删除 `master_t &master` 成员与对应 `registry.get_widget<master_t>()` 初始化；
- 删除 `master.log_runtime_state(...)`；
- 删除 `clock.log_debug_state(...)`；
- 删除 `peek_poke.log_debug_state(...)`；
- 保留 `+firesim-driver-debug` 的轻量 driver 进度打印：
  `step/poll/total_poll/tcycle/hcycle/is_done/terminate bridge`。

该修改的意图是：保留必要的 host driver 进度 breadcrumb，但不再依赖已删除的 synthetic
OCL debug 寄存器，也不再扩大 OCL 控制面观测负担。

## 验证

残留搜索为零：

```text
log_runtime_state
log_debug_state
FIRESIM MASTER DEBUG
FIRESIM CLOCK DEBUG
FIRESIM PEEKPOKE DEBUG
HEALTH_
```

`git diff --check` 通过。

随后重新删除 single-core NIC generated-src / output / built-hwdb entry，并启动 fresh
build：

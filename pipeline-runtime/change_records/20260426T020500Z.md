## 修改内容

- `toHost` 方向改为整组同步：
  - `hPort.nicOutValid.ready`
  - `hPort.nicOutBitsData.ready`
  - `hPort.nicOutBitsKeep.ready`
  - `hPort.nicOutBitsLast.ready`
  都只在 `toHostFire` 时拉高。
- `fromHost` 方向改为整组同步：
  - `hPort.nicIn*`
  - `hPort.macAddr`
  - `hPort.rlimit*`
  - `hPort.pauser*`
  都只在 `fromHostFire` 时拉高 `valid`。
- 增加 partial-fire / would-block / token-available debug regs，并在 host driver 的 `dump_host_debug()` 中打印。
- 旧 `currentBlockedReason` 和 ready-blocked counters 改为基于 `fromHostTokenAvailable` / queue-ready 状态，而不是基于已经 gated 的 channel valid。

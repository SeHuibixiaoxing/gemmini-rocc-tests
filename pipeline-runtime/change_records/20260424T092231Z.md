## 原因

- 当前 NIC 失败点发生在 guest Linux 之前，继续加 guest 日志没有判别力。
- 之前只有 `push()==0` 这一条现象，无法区分：
  - host stream occupancy 误读
  - bridge 不取 token
  - target 前小队列不流动
  - target 返回路径阻塞导致 lockstep `tFire` 断掉
- 因此需要一组低扰动、直接可读的 bridge 内部状态。

## 原因

- 近几轮 live run 已反复证明：
  高频文本探针会移动 frontier，
  需要把“观测扰动”和“真实 blocker 穿过”分开
- 之前 triage 输出虽然能看 frontier，
  但还不能直接生成下一轮单变量 rerun 配置
- 之前 fixed profile 会把 trigger env 覆盖回默认值，
  使 triage 产物无法直接落地

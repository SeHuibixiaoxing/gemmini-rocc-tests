## 修改内容

### Runtime

- 新增：
  - `sims/firesim/deploy/config_runtime_f2_rocket_singlecore_nic_gdbserver_smoke_notrace_quiet_preserve_30mhz.yaml`
- 用途：
  - 同一 AGFI / 同一 gdbserver workload。
  - 去掉 `+targetcycle-debug` 与 SimpleNIC round debug，只保留长 heartbeat。
  - 用来区分“调试输出扰动”与“硬件桥接语义死锁”。

### SimpleNIC bridge

- `generators/firechip/goldengateimplementations/src/main/scala/SimpleNICBridge.scala`
  - `macAddr`、`rlimit`、`pauser` 改为每个 target cycle 都 `valid`，不再只在 HTNT token 存在时驱动。
  - host->target 的空 token（`data_in_valid=0`）直接从 `htnt_queue` 丢弃。
  - host->target payload token 仍必须等 `nicIn/mac/rlimit/pauser` 全部 ready 才 dequeue。
  - target->host 空 token 在 `ntht_queue` 满时旁路丢弃，避免空输出 token 反压 target。
  - target->host payload token 仍必须等 `ntht_queue` ready。
  - 增加可综合计数器：
    - `to_host_empty_bypass_count64`
    - `to_host_empty_enqueue_count64`
    - `to_host_payload_blocked_count64`
    - `from_host_empty_drop_count64`
    - `from_host_payload_blocked_count64`
  - 增加当前状态寄存器：
    - `from_host_payload_token_available`
    - `from_host_empty_token_available`
    - `from_host_empty_drop`
    - `to_host_payload_valid`
    - `to_host_empty_valid`
    - `to_host_empty_bypass`
    - `to_host_empty_enqueue`
    - `to_host_payload_blocked`

### Host driver debug

- `generators/firechip/bridgestubs/src/main/cc/bridges/simplenic.h`
  - 补齐新增 MMIO register 字段。
- `generators/firechip/bridgestubs/src/main/cc/bridges/simplenic.cc`
  - `dump_host_debug()` 打印新增 bypass/drop/payload-blocked 计数与当前状态。
  - blocked reason 文本改为区分 payload 阻塞，避免把空 token 旁路误报成真实 payload 卡死。

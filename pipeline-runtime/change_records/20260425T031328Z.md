## 修改内容

### 1. `SimpleNICBridge` handshake 修复

- 移除 `hPort.fromHost.hValid` 对 `hPort.fromHost.hReady` 的依赖。
- 保留 `tFire` 作为真实 token 消费/产生的唯一推进条件。
- 将 `target.in.valid` 也纳入 `tFire` 门控，避免 target 侧看到没有被 bridge 实际消费的输入 token。

### 2. target-side 可综合 debug regs

新增读取项：

- bridge 驱动信号：`local_queues_ready`、`target_cycle_ready`、`to_host_ready_drive`、`from_host_valid_drive`
- queue raw ready/valid：`htnt_queue_*`、`ntht_queue_*`
- target token 内容：`target_in_bits_*`、`target_out_bits_*`

### 3. host-side `simplenic` 调试增强

- 同步扩展 `SIMPLENICBRIDGEMODULE_struct`。
- 失败快照打印新增硬件 debug regs。
- 新增 `+simplenic-round-debug`，可在成功 round 打印快照。
- 新增 `+simplenic-relaxed-required-bytes`，用于诊断 stream threshold 造成的 0 字节/部分字节差异。

### 4. no-Trace singlecore NIC smoke 配置

- 新增 `FireSimRocketNICNoTraceConfig`。
- 新增独立 F2 build/build-recipes/runtime/hwdb 配置。
- 新增 local metasim build recipe，方便后续在不构建 bitstream 的路径上先做 FireSim metasim 尝试。

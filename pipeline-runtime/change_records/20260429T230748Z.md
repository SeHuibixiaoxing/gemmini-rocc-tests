# 20260429T230748Z - NIC switch root SSHPort / mac2port bounds fix

类别：`gdbserver` / NIC / FireSim switch

对应 debug record：`../debug_records/20260429T230748Z.md`

## 修改内容

1. `sims/firesim/deploy/runtools/switch_model_config.py`
   - 为生成的 switch config 增加 `MAC2PORT_SIZE`。
   - 修正 root switch 上自动加入的 `SSHPort` 计数方式：
     - `NUMDOWNLINKS` 只包含真实 downlink。
     - `NUMUPLINKS` 包含真实 uplink 加 root `SSHPort`。
   - 这样 `mac2port` 表中“任意 uplink”的哨兵值重新等于 `NUMDOWNLINKS`，可路由到 host TAP 方向。

2. `sims/firesim/target-design/switch/flit.h`
   - 在 `mac2port[sendport]` 前增加边界检查。
   - host TAP 动态 MAC suffix 超过表长时，不再越界读；有 uplink 时路由到 first uplink，无 uplink 时按 unknown unicast flood。
   - 增加 `mac2port_oob` / `mac2port_no_uplink` debug 输出，后续能直接看到 unknown MAC 的 suffix、表长和动作。
   - 避免 `NUMUPLINKS == 0` 时执行 `rand() % NUMUPLINKS`。

3. `sims/firesim/target-design/switch/switch.cc`
   - 调用 `get_port_from_flit()` 时传入真实 sender 端口，便于 switch debug 日志复原现场。

## 验证

- `python -m py_compile sims/firesim/deploy/runtools/switch_model_config.py` 通过。
- 用当前 switchconfig include 路径直接编译更新后的 `switch.cc/flit.h` 通过。
- 生成逻辑抽样确认单节点 root switch 会变为：
  - `NUMPORTS 2`
  - `NUMDOWNLINKS 1`
  - `NUMUPLINKS 1`
  - `MAC2PORT_SIZE 3`

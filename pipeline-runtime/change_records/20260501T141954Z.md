# 为 NIC target-to-host bit-clear 定位补齐 adapter stage first16 快照

日期：2026-05-01T14:19:54Z

## 修改目的

上一轮证据已经把问题缩到：

```text
guest TX checksum 后
  -> IceNet TX / send path
  -> SimpleNIC hPort.nicOut
  -> ntht_queue
  -> NICTokenToBigTokenAdapter
  -> CPU-managed stream / F2 PCIS read
  -> host simplenic target_to_switch_pull
```

已有 `hPort.nicOut` first16 与 host token dump 还不足以区分 adapter packing 与
CPU-managed stream / PCIS readback。因此本轮只加可综合观测，不改变 NIC 功能语义。

## 代码修改

文件：

- `generators/firechip/goldengateimplementations/src/main/scala/SimpleNICBridge.scala`
- `generators/firechip/bridgestubs/src/main/cc/bridges/simplenic.h`
- `generators/firechip/bridgestubs/src/main/cc/bridges/simplenic.cc`

新增观测：

- `nicbig_ntht_first_*`：`NICTokenToBigTokenAdapter.ntht` 输入侧的最新 packet first16
  `data/keep/last/flit_idx/valid_mask/done/seq`；
- `nicbig_pcie_first_*`：`NICTokenToBigTokenAdapter.pcie_out` 输出侧解包后的最新 packet
  first16 `data/keep/last/flit_idx/valid_mask/done/seq`；
- host dump 中新增：
  - `SIMPLENIC TX FIRST16 [...] stage=hport`
  - `SIMPLENIC TX FIRST16 [...] stage=nicbig_ntht`
  - `SIMPLENIC TX FIRST16 [...] stage=nicbig_pcie`

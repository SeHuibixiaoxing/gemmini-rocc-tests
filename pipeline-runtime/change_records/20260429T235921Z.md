# 临时关闭 IceNet checksum offload 做 NIC payload corruption 判别实验

日期：2026-04-29T23:59:21Z

## 修改

- 文件：`software/firemarshal/boards/firechip/drivers/icenet-driver/icenet.c`
- 将原来的 `#define CONFIG_ICENET_CHECKSUM` 改为 `#undef CONFIG_ICENET_CHECKSUM`。

## 目的

这不是硬件 RTL 修改，不需要重新构建 bitstream。目的只是用同一颗最新 single-core NIC AGFI 做判别实验：

- 如果关闭 offload 后 ICMP payload corruption 消失，则当前错误收敛到 IceNet TX checksum rewrite/offload 控制链。
- 如果关闭 offload 后 corruption 仍在，则 checksum offload 分支被排除，下一轮应把可综合观测加到 target->host stream / SimpleNIC token packing / CPU stream pull 链路。

## 预期软件效果

由于 `CONFIG_ICENET_CHECKSUM` 不再定义：

- `icenet_open()` 不再写 `ICENET_CSUM_ENABLE`
- `post_send()` 不再写 `ICENET_TXCSUM_REQ`
- `icenet_probe()` 不再宣告 `NETIF_F_HW_CSUM` / `NETIF_F_RXCSUM`
- Linux 网络栈会在软件里完成需要的 TX checksum

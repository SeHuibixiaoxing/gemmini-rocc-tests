## 修改内容

### 1. 新增 TargetCycleDebugWidget

新增 FPGATop 级可综合 debug widget，记录：

- HostPort `toHost/fromHost` valid/ready masks。
- FAME wire channel valid/ready masks。
- FAME ready-valid channel forward/reverse valid/ready masks。
- live、first trigger、last trigger 三组快照。
- trigger count、first/last trigger host cycle、各类 channel count。

host driver 支持：

- `+targetcycle-debug`
- `+targetcycle-debug=1`
- `+targetcycle-debug<N>=1`
- `+targetcycle-debug-limit=N`
- `+targetcycle-debug-labels=0/1`

### 2. 扩展 SimpleNIC debug regs

新增 SimpleNIC 侧计数和快照：

- global/local blocker counters。
- `from_host_ready` 低电平 streak/max streak。
- PCIS input/output backpressure counters。
- `htnt` / `ntht` token 字段。
- full 512-bit PCIe bigtoken hex。

host dump 在 init、round success、pull mismatch、push mismatch 时统一打印这些寄存器。

### 3. 扩展 CPU-managed stream 阻塞日志

`push()` / `pull()` 在返回 0 前输出 stream queue 的 count/space/threshold 信息，方便区分 FIFO 满/空和底层 PCIS 读写失败。

### 4. 更新 runtime plusargs

no-Trace gdbserver smoke runtime 已加入：

```text
+simplenic-round-debug=8 +targetcycle-debug=1 +targetcycle-debug-limit=8
```

## 修改内容

### 1. `switch0-*-build` 改为按修改时间选最新

原脚本使用：

```bash
find "${switch_root}" ... -name 'switch0-*-build' | sort
```

然后取最后一个目录。

问题：

- `switch0-*-build` 的后缀是随机 disambiguator
- 字典序最后一个目录不等于最新目录

本轮改成：

- 用 `find ... -printf '%T@ %p\n'`
- 按 mtime 数值排序
- 再取最后一个目录

并在脚本里补了注释，明确说明：

- 这些目录后缀不是时间戳
- 必须按修改时间挑选，才能 patch 到当前 `infrasetup` 刚生成的 switch

## 修改原因

静态排查显示：

- `infrasetup` 这轮刚生成并下发的是 `switch0-F4VA...-build`
- 但 `run` 阶段 network-prepare 却把历史 `switch0-UTY0...-build` 改成了 `SSHPort` 版
- 原因正是 `UTY...` 在字典序上排在 `F4...` 后面

这会导致：

- `run` 真正启动的 switch
  并不一定是当前这轮 `infrasetup` 对应的 switch
- 从而把 host-side `gdbserver` 网络链路调试变成带环境噪声的随机过程

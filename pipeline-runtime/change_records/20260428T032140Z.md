## 修改背景

`agfi-0979aad323cd3ca4d` 已经证明上一轮 `fromHostValidDrive` 修复能让
NIC smoke 进入 Linux 和用户态，但 host `tap0` 只有 TX、没有 RX。现场显示

消费大量 empty token。

## RTL/Bridge 修复

- 将 SimpleNIC host port 改成显式 channelized host IO：
  `SimpleNICBridgeHostIO`，分别暴露 `nicOut`、`nicIn`、`macAddr`、
  `rlimit`、`pauser`。
- `nicIn` 持续 valid，并由 bridge 自己生成空 token；真实 payload 只改变
  `bits.valid/data/keep/last`，不再依赖 host->target token 是否存在来驱动
  leaf channel valid。
- CPU stream 中的 empty host->target token 直接 drop：
  `fromHostEmptyDrop = fromHostEmptyTokenAvailable`。
- 真实 host->target payload 进入 pending/current 两级 staging，避免队头
  empty token、后续 payload 或 ready 低造成 target-facing bits 组合变化。
- target->host 方向只让真实 payload 进入 `ntht_queue`；empty token 在队列满
  时可以 bypass，避免空包反压 target。
- `macAddr`、`rlimit`、`pauser` 改成持续 valid，避免配置 sideband 与
  `nicIn` 继续形成隐含 lockstep。

## 可综合 debug 增强

新增/扩展 MMIO debug regs，覆盖：

- channel ready/valid/fire mask；
- `htnt_queue` / `ntht_queue` 计数与 enq/deq；
- CPU stream `pcie_in_bits` / `pcie_out_bits`；
- target-facing `target_in_bits_*` / `target_out_bits_*`；
- from-host empty drop、payload capture、payload deq；
- current/pending payload valid/data/keep/last；
- payload capture 计数、最后 capture cycle/data/meta；
- target cycle blocked reason 与 first/last blocked snapshot。

host driver `dump_host_debug()` 同步读取这些 regs，并继续保留 pending peer
snapshot 与 `peer_flit_sample`，用于失败时一次性复原 host->target 全链路现场。

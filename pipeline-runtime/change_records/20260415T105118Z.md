# 2026-04-15 10:51:18 UTC

## Scope

修复 pairdummy sbus128 fixed workflow 中的一个 host 配置传播缺陷：
外部 shell 传入的 breadcrumb overlay 会被 `pairdummy_sbus128_fixed_env.sh` 无条件覆盖，导致 breadcrumb-only rerun 实际失效。

## Files Changed

- `scripts/pairdummy_sbus128_fixed_env.sh`

## Root Cause

该脚本此前对以下变量使用了硬编码导出：

- `PIPELINE_RUNTIME_BREADCRUMB_ENABLE`
- `PIPELINE_RUNTIME_BREADCRUMB_PATH`
- `PIPELINE_RUNTIME_BREADCRUMB_SEGMENT`
- `PIPELINE_RUNTIME_BREADCRUMB_GLOBAL_STAGE`
- `PIPELINE_RUNTIME_BREADCRUMB_LOCAL_STAGE`
- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH`
- `PIPELINE_RUNTIME_BREADCRUMB_STAGE_RADIUS`
- `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS`

因此即使外部已经 `export PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH=5`，
workflow 内部 source fixed env 后仍会把它重置回默认值。

## Fix

对白名单 breadcrumb 变量改为：

```bash
export VAR_NAME="${VAR_NAME-default}"
```

语义参数仍保持固定；
只有 selected breadcrumb filters 与 trigger selectors 可以透传外部 overlay。

## Validation

验证命令：

```bash
export PIPELINE_RUNTIME_DEBUG_TRIGGER_ENABLE=0
export PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH=5
export PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS=0
generators/gemmini/software/gemmini-rocc-tests/pipeline-runtime/scripts/pairdummy_sbus128_workflow.sh show
```

验证结果：

- `breadcrumb_subbatch=5`
- `breadcrumb_subbatch_radius=0`
- `debug_preflight_status=pass`

## Impact

这次修复保证后续 breadcrumb-only rerun 真正使用收窄后的 guest env；
否则任何基于 `subbatch` 过滤的低扰动观测结论都不可信。

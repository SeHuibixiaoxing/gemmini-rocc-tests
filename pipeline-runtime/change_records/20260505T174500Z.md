# 20260505T174500Z change record

## Summary

Prepared a parallel cfg32 NIC no-TraceIO F2 build variant as a resource-reduced fallback for pipeline-runtime
remote `gdbserver` debugging.

## Hardware/config changes

- Added `FireSimGemminiReRoCCPairDummy16x16C4P12Sbus128NICNoTraceConfig` in
  `generators/firechip/chip/src/main/scala/TargetConfigs.scala`.
- Added build config:
  `sims/firesim/deploy/config_build_gemmini_rerocc_pairmanager_dummy16x16_4c12p12_sbus128_cfg32_nic_notrace.yaml`.
- Added build recipe:
  `sims/firesim/deploy/config_build_recipes_f2_gemmini_rerocc_pairmanager_dummy16x16_4c12p12_sbus128_nic_notrace.yaml`.

## Rationale

The mainline cfg32 NIC build uses `WithFireSimConfigTweaks`, which enables TraceIO, and
`WithDefaultFireSimBridges`, which includes `WithTracerVBridge`. Because remote `gdbserver` does not need
TracerV and an earlier cfg32 NIC build failed placement near the resource limit, disabling TraceIO is a
reasonable parallel fallback.

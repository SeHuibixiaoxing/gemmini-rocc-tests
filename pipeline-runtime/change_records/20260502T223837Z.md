# 为 NIC target->host payload corruption 增加 host/switch 观测

日期：2026-05-02T22:38:37Z

## 背景

`agfi-032d10150efc1d4ec` 已经能 boot 到 Linux 并启动 `gdbserver`，但 pcap 证明
guest->host 返回包存在固定位置 payload/checksum corruption。pattern ping 将最强错误
定位到 `flit % 7 == 1` 的固定 byte lane。

## 修改文件

```text
sims/firesim/target-design/switch/baseport.h
sims/firesim/target-design/switch/shmemport.h
sims/firesim/target-design/switch/sshport.h
sims/firesim/deploy/config_runtime_f2_rocket_singlecore_nic_gdbserver_smoke_notrace_relaxed_tokendebug_preserve_30mhz.yaml
```

## 修改内容

- `BasePort::push_input()`：
  - 将 `input_packet` debug limit 从 64 提到 128；
  - 新增 `input_packet_flit`，打印每个 packet 前 16 个 flit。
- `ShmemPort::{recv,send}()`：
  - 将 debug limit 从 64 提到 128；
  - 新增 `recv_flit` / `send_flit`，打印每轮前 16 个有效 flit 的 token id、data、last。
- `SSHPort::send()`：
  - 将 `output_buf` / `tap_send` debug limit 从 64 提到 128；
  - 新增 `tap_send_word`，打印 TAP 发送帧前 16 个 64-bit word；
  - 新增 `tap_send_bytes`，打印 TAP 发送帧前 160 字节。
- 新增 token-debug runtime：
  - 保持同一 single-core NIC AGFI；
  - 打开 `+simplenic-token-debug=128`；
  - 使用独立 runfarm tag `f2rocketsinglecorenictokendebug`。

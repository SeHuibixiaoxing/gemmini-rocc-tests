## 修改内容

### 1. 回滚 target-side debug MMIO

从 `SimpleNICBridge.scala` 删除了上一轮新增的：

- `debug_*` 计数器
- `debug_flags`
- `genROReg(debug_...)`

同时从 `simplenic.h` 删除了对应的新增 MMIO struct 字段。

结果：

- host 与当前 AGFI 的 MMIO map 重新兼容

### 2. 新增 host-only stream 失败诊断

在 `cpu_managed_stream` 中新增：

- `stream_name()` accessor
- `push_blocked` 打印
- `pull_blocked` 打印

只在 `push()` / `pull()` 因 occupancy 或 threshold 不满足而返回 `0` 时输出。

### 3. 新增 `simplenic` host 上下文打印

新增：

- `dump_host_debug(...)`

用于在 mismatch 现场打印：

- 当前轮次
- 链路参数
- stream index
- poll byte
- bridge `done`

## 原因

- 用户指出上一轮 target-side 调试方案虽然逻辑上有信息量，
  但方法上不成立：
  代码改了 RTL，却没有同步重建 bitstream。
- 这会导致 host/target MMIO map 不匹配，无法用于当前 AGFI。
- 因此必须改成纯 host-side 方案。

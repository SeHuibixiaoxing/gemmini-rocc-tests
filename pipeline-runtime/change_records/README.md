# Pipeline Runtime Change Records

这个目录专门存放每一轮实际修改的记录。

约束：

- 每一轮修改必须新建一个单独文件，文件名使用 UTC 时间戳，例如：
  `20260413T163651Z.md`
- 不要复用旧文件追加新一轮内容
- 每个文件至少记录：
  - 本轮目标
  - 关联 debug record
  - 修改文件
  - 修改内容
  - 修改原因
  - 验证
  - 风险 / 后续

建议结构：

```md
# Change Record <UTC timestamp>

## 目标
## 关联记录
## 修改文件
## 修改内容
## 原因
## 验证
## 风险 / 后续
```

补充：

- 原始记录文件保持扁平时间戳命名；按调试类别的聚合索引见：
  `CATEGORY_INDEX.md`

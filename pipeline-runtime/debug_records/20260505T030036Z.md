expect exit code：`5`。

## 判断

这轮失败不是旧 AGFI 的基础 remote gdbserver / NIC 链路失败。关键差异是当前
`run_remote_gdbserver_software_expect_smoke.sh` 在 05-01/05-02 已验证矩阵之外，
又加入了“删除当前断点并设置条件断点”的步骤。

05-01 记录明确说明“条件断点没有单独跑命令验证”；旧能力矩阵真正需要的是：

- `target remote`
- 多个普通 software breakpoint
- `continue`
- `next`
- `info threads`
- `thread apply all bt`
- 寄存器读取、反汇编、变量/内存读写
- 线程切换
- `Ctrl-C` 抢回控制
- `detach`

因此下一步应把 smoke harness 对齐到旧能力矩阵：去掉默认条件断点，把收尾改回
`Ctrl-C` 后 `detach`。如果后续确实要验证条件断点，应作为单独可选测试，不能混入
1BP 基线恢复标准。

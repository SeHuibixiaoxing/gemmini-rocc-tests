# 20260504T162003Z - Static checkpoint: remove TargetCycleDebugWidget from conservative 1bp F2 path

## Scope

This checkpoint records the static refresh after removing the default target-cycle debug widget from the conservative 1bp F2 build path.

The target remains:

- Config: `FireSimRocketNICNoTraceConfig + BaseF2Config`
- Type: single-core Rocket + NIC + no TraceIO + 30MHz
- Breakpoint count: one hardware breakpoint, not the 8BP variant

## Why This Was Changed

The prior conservative 1bp build attempt failed timing and the generated simulator memory map still contained:

```text
TargetCycleDebugWidget_0
```

That widget is not required for the old gdbserver pass condition. It also adds a broad ready/valid observation surface over host-port and FAME channels. For the conservative rebuild, the hardware should stay closer to the old passing 1bp AGFI and avoid unrelated observability logic.

The change removes the default `TargetCycleDebugWidget` instantiation and its fanout sampling from:

`sims/firesim/sim/midas/src/main/scala/midas/core/FPGATop.scala`

It intentionally keeps the existing ChannelizedHostPort connection fix in the same file.

## 设计理由

这个改法的优点是：

1. 继续复用当前已工作的 pair-manager + cfg32 硬件主线
2. 不需要额外引入新的 Chipyard Scala target class
3. NIC 只通过 FireSim 现成的 `WithNIC` trait 叠加
4. 如果后续生成 DTS 中出现 `ice-nic`，就可以直接切回当前 gdbserver SOP 继续推进

## 关键判断

该 AGFI 仍复现 valid-drive 修复前的行为：

```text
from_host_token_available=1
from_host_valid_drive=0
```

同时可见：

```text
chan_from_host would_valid=0x7ff
chan_from_host valid=0x0
tap0 RX=0
```

这说明 host 侧流量已经进入 SimpleNIC host driver / `htnt_queue`，但
host-to-target leaf `valid` 没有被真正拉起，guest NIC 收不到 host 注入包。
这与 `20260426T052258Z` 中已经修到源码里的 `fromHostValidDrive` 问题吻合。

因此，本轮 preserve run 的结论不是“validdrive 修复失败”，而是：

- `agfi-038e74ee0655e3a2a` 仍是 validdrive 之前的已完成 AGFI；
- 它稳定复现 `from_host_token_available=1 && from_host_valid_drive=0`；
- 当前正在构建的 validdrive bitstream 完成后，才应验证该问题是否消失。

## 脚本结果

expect 子进程 exit code 为 `0`，但 wrapper 最终返回 `1`：

```text
[remote-swbreak-expect] expect_rc=0
missing GDB_MARK_CONNECTED
```

原因是 harness 中的 `puts "GDB_MARK_*"` 进入了 `expect-driver.stdout`，而不是
`remote-swbreak.expect.log`；wrapper 只 grep transcript 文件，导致 false negative。

后续已修正 wrapper：marker、`0xabcdef` 和 thread evidence 同时检查 transcript 与
`expect-driver.stdout`。

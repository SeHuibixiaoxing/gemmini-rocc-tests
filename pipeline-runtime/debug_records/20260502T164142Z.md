## 下一步判定标准

下一轮 single-core NIC AGFI 构建前必须强制刷新生成物。构建进入 Vivado 后必须检查：

应当存在：

- Verilog 中的 `from_host_valid_drive`；
- Verilog 中的 `from_host_empty_drop`；
- Verilog 中的 `from_host_current_payload_valid`；
- Verilog 中的 `TargetCycleDebugWidget`；
- driver 中的 `+simplenic-empty-switch-poll-interval`；
- driver 中的 `empty_rounds_skipped_switch`；
- driver 中的 `+cpu-managed-stream-debug`；
- driver 中的 `targetcycle-debug`。

不应当存在：

- `HEALTH_MAGIC`；
- `HEALTH_COUNTER`；
- `FIRESIM MASTER DEBUG`；
- `FIRESIM CLOCK DEBUG`；
- `FIRESIM PEEKPOKE DEBUG`；
- `ctrl_live`。

如果新 AGFI 仍在 Linux 前失败，必须先保留远端现场和本地结果，再用 target-cycle debug
和生成物 freshness 证据钉死原因；不能把它直接归因到 `gdbserver`。

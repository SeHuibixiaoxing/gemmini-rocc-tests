## Result

No usable AGFI/AFI was produced.

Vivado completed place and route, but the post-route DCP did not meet timing. The tmux wrapper exited with code `1` after result copy-back also hit local infrastructure issues.

Key timing evidence from the copied reports:

- `post_route_timing.rpt`: worst reported setup slack `-3.205ns`
- Vivado log final summary around post-route physical optimization:
  `WNS=-3.205`, `TNS=-4794.858`, `WHS=-3.961`, `THS=-4230.232`
- AWS FPGA log line reported negative setup and hold paths, including:
  - setup: `WRAPPER/RL_SHIM/PIPE_RST_OUT_N/pipe_reg[0][0]/C --> WRAPPER/CL/ddr_ready_pre_sync_meta_reg/CLR`
  - hold: `WRAPPER/CL/ocl_fsim_ar_fire_count_reg[6]/C --> WRAPPER/RL_SHIM/PIPE_STATUS1/pipe_reg[0][22]/D`

The FireSim manager then failed while rsyncing results because:

- local root filesystem was full (`/dev/root` at 100%)
- SSH known_hosts had stale keys for `192.168.1.58`

Those copy-back failures are secondary. The primary build result remains a timing failure and the output is not a valid gdbserver test target.

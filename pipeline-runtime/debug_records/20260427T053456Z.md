## SimpleNIC 快速定位

- 报错字符串来自：
  `generators/firechip/bridgestubs/src/main/cc/bridges/simplenic.cc`
  的 `simplenic_t::tick()` from-host stream `push()` 路径。
- 当前源码已经包含 cooperative retry 逻辑：
  `push(...) == 0` 时记录 `tick_push_blocked_retry` 并 `return`，不应直接 exit。
- 但本轮远端 `FireSim-f2` 没有打印当前源码新增的：
  - `using simplenic round debug`
  - `using simplenic relaxed required bytes`
  - `tick_push_blocked_retry`
- 对 hwdb 指向的 driver bundle 执行 `strings` 也只看到旧的
  `ERR MISMATCH! on writing tokens in...`，没有新增 debug/retry 字符串。
- 因而当前最可能状态是：
  **AGFI 正确指向用户要求的 cfg32_nic bitstream，但 hwdb 的 `driver_tar`
  仍是旧 SimpleNIC host driver，未包含当前源码中的 0-byte push retry / NIC 调试修改。**

这解释了为什么本轮在 `push()` 返回 0 字节时直接退出，且完全没有进入 Linux。

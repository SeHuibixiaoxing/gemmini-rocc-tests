## 静态分析
- `address2` 目标并不是单独新分配的一块随机内存。
- 它和 `address` 一样，都通过 `resolve_model_addr_to_ptr()` 映射到同一个 `synthetic model blob`。
- `synthetic model blob` 当前实现是：
  - `mmap(MAP_PRIVATE|MAP_ANONYMOUS)`
  - `prefault`
  - `mlock`
- 因此，基于当前代码，不能简单把问题归因为“address2 没锁页”。

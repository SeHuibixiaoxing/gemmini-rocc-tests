# 2026-04-15 10:51:18 UTC

## Round Goal

验证 breadcrumb-only rerun 的 overlay 是否真的透传到 fixed workflow。

## Finding

初次检查 `pairdummy_sbus128_workflow.sh show` 时发现：

- 外部 shell 已设 `PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH=5`
- workflow 输出仍显示 `breadcrumb_subbatch=any`

这说明新加入的 guest-env render 支持虽然存在，但在 workflow 执行链上被更早的 fixed-env 层覆盖。

## Static Root Cause

`scripts/pairdummy_sbus128_fixed_env.sh` 对 breadcrumb 变量使用无条件硬编码导出。
因此外部 overlay 在进入 workflow 之后立即丢失。

## Action

将 selected breadcrumb 变量改成 `${VAR-default}` 形式，只对白名单保留外部值。

## Verification

修复后再次执行：

```bash
export PIPELINE_RUNTIME_DEBUG_TRIGGER_ENABLE=0
export PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH=5
export PIPELINE_RUNTIME_BREADCRUMB_SUBBATCH_RADIUS=0
generators/gemmini/software/gemmini-rocc-tests/pipeline-runtime/scripts/pairdummy_sbus128_workflow.sh show
generators/gemmini/software/gemmini-rocc-tests/pipeline-runtime/scripts/pairdummy_sbus128_workflow.sh debug-preflight
```

结果：

- `breadcrumb_subbatch=5`
- `breadcrumb_subbatch_radius=0`
- `debug_preflight_status=pass`

## 静态结论

本轮新增的 global widget 更接近真实根因位置。上一轮 SimpleNIC regs 显示 NIC 本地可推进，但 `fromHost.hReady=0`；在 FAME/HostPort 结构中，这个 ready 不是 NIC 单点决定，而是全局 target-cycle finishing / channel fired 状态的结果。

因此下一颗 AGFI 的关键日志应先看：

1. `TARGETCYCLE DEBUG HPORT [first|last]`
2. `TARGETCYCLE DEBUG CHANNEL/RV [first|last]`
3. `SIMPLENIC DEBUG REGS [tick_push_mismatch]`
4. `CPU_STREAM DEBUG push_blocked`

若 `TargetCycleDebugWidget` 指向 AXI4/blockdev/TSI/UART/reset 的某个 channel，则下一步应进入对应 bridge；若仍只指向 SimpleNIC，则再回到 NIC token adapter/queue 交界。

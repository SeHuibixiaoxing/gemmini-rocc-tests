## 分析

- 当前 round 的关键结论不是 “manager/SSH 又坏了”，而是：
  host watchdog 成功抓到了 guest 已进入 runtime 的证据，并在 freeze 后主动清理了实例。
- 当前真实缺口也不是 guest 文件系统日志本身，而是：
  watchdog 在 timeout capture 前没有把 `TRACEFILE-C*` 一并带回，
  导致这轮 `TracerV` 仍无法回答“最后停在哪条退休指令”。
- 由于这轮 guest 已经再次推进到
  `tensor=1000001 fixed-load`
  且 heartbeat 也冻结，
  下一轮最有价值的单变量不是继续加新的 guest 文本日志，
  而是保留当前 guest 观测面不变、只增强 watchdog 对 `TRACEFILE-C*` 的回收。
